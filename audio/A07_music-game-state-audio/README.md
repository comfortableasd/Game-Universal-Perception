# A07 — Music & Game-State Audio

**Objective:** Analyze music segments, intensity, transitions, beats/onsets and audio cues correlated with game phases.

**Applicable games:** rhythm, racing, sports and action games. Candidates: Beat Saber, DJMAX, Forza Horizon 5, EA SPORTS FC and action games.

**Baseline:** music/audio event analysis, onset detection and temporal segmentation.

**Evaluation:** onset F1/timing error, segment classification F1 and cross-game soundtrack robustness.

**Caution:** music intensity is not ground truth for combat or danger. Validate any game-state mapping independently.

**Status:** Planned specification.
