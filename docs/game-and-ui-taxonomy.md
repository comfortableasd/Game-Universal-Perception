# Game and UI Taxonomy

Genre and UI architecture are separate axes. One game may contain multiple modes and UI patterns.

| Game family | Examples | Common perception tasks |
|---|---|---|
| FPS | DOOM Eternal, Metro Exodus, Borderlands 3, Far Cry 6 | weapon, firing, reload, ammo, reticle, minimap |
| TPS/action adventure | GTA V, RDR2, Horizon Forbidden West, God of War Ragnarök | character, weapon, health, target, interaction |
| ARPG/soulslike | Elden Ring, Lies of P, Black Myth: Wukong, Nioh 2 | health, boss bar, stamina, skill, status |
| MMORPG | World of Warcraft, FFXIV, Black Desert Online | skill, buff, target, inventory, text |
| MOBA | Dota 2, League of Legends, Smite 2 | skill, minimap, health, scoreboard |
| RTS | StarCraft II, Age of Empires IV, Company of Heroes 3 | unit, resource, minimap, production |
| 4X/strategy | Civilization VI, Stellaris, Crusader Kings III | map, resources, panels, events |
| Racing/driving | Forza Horizon 5, GT7, ACC, ETS2, BeamNG.drive | speed, RPM, gear, route, rank |
| Sports | EA SPORTS FC, NBA 2K | score, timer, player, action |
| Survival/sandbox | Rust, ARK, Valheim, Subnautica | health, inventory, resources, warnings |
| Survival horror | Resident Evil 4, Resident Evil Village | inventory, ammo, health, interaction |
| Fighting | Street Fighter 6, Tekken 8, Mortal Kombat 1 | health, timer, combo, action |
| Rhythm | Beat Saber, DJMAX, Muse Dash, osu! | lanes, notes, hit timing, combo |
| Simulation/management | Cities: Skylines II, Planet Zoo, Farming Simulator | panels, resources, warnings, objects |
| Tactical/tower defense/puzzle | XCOM 2, Bloons TD 6, Portal 2 | grid, unit, objective, interaction |

## UI architecture families
1. Fixed HUD overlays.
2. Multi-panel management interfaces.
3. Map/navigation interfaces.
4. Modal menus and dialogs.
5. Object-attached/world-space UI.
6. Vehicle dashboards and instrument clusters.
7. Dialogue/subtitle interfaces.
8. Touch/controller action overlays.
9. Timeline/rhythm lanes.
10. Context-sensitive prompts and tooltips.

Applicability is a hypothesis, not a support claim. A task must be visibly present and tested in the relevant game version, mode, language and display configuration.
