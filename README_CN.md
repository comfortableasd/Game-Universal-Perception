# Game Universal Perception（GUP）

面向电子游戏的跨游戏通用视觉感知框架。GUP 按功能任务组织模型，研究同一视觉能力如何跨游戏、跨 HUD、跨分辨率复用。

> 当前仓库处于研究规划与工程脚手架阶段。目录和指标是研发规范，不代表模型已经实现或达到目标；不承诺任意游戏 100% 准确。

## 关键原则
- 共享视觉编码器 + 任务专用 Head；不强迫所有任务使用同一模型。
- DINOv3 是候选 Backbone。Patch tokens 用于空间特征，CLS 用于全局上下文。
- PCA-to-RGB 用于特征检查，不替代原始高维特征。
- 时序任务（开枪、换弹、动作）必须用视频事件评测。
- 证据不足时输出 UNKNOWN；不能把隐藏输入或游戏状态当作 RGB 可观测事实。
- 采用按游戏隔离的跨游戏评测，防止相邻帧泄漏。
